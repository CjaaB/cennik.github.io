# Wizytowka Car All Detailing

Pliki drukowane w `extras/wizytowka/`.

## Zawartosc folderu (wymagane)

- `wizytowka-*-front.svg` / `wizytowka-*-tyl.svg` - projekty
- `logo.png` - kopia logo (musi byc w tym folderze)
- `qr-car-all-detailing.svg` - kod QR (musi byc w tym folderze)
- `podglad.html` - podglad w przegladarce

## Podglad

Otworz `podglad.html` z tego folderu (dwuklik). Jesli logo lub QR nie widac - sprawdz czy `logo.png` i `qr-car-all-detailing.svg` leza obok plikow SVG.

## Druk

1. Otworz wybrany SVG w przegladarce lub Inkscape.
2. Eksportuj do PDF.
3. Format docelowy: **90 x 50 mm**, druk dwustronny (front + tyl tego samego wariantu).
