## Format

Projekty mają format `94 x 54 mm`, czyli wizytówka `90 x 50 mm` z około `2 mm` zapasu pod spad.

## Eksport do druku

Najbezpieczniej:

1. Otworzyć plik SVG w Inkscape, Illustratorze, Figmie albo Affinity Designer.
2. Sprawdzić dane kontaktowe i ewentualnie poprawić tekst.
3. Wyeksportować do PDF w jakości drukarskiej.
4. W drukarni poprosić o potwierdzenie spadów i marginesów bezpiecznych.

Logo jest podlinkowane jako `../assets/logo1.png`.
